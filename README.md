# KC FILE

現代化的 Windows 檔案管理器。

## 特色

- **KC 佈景主題**：多套配色，深色與淺色都會跟著主題變換色調
- **背景材質**：Mica、Acrylic 等材質會透出視窗、工具列與側欄，每種材質都有各自的 KC 色調
- **全新設定介面**：首頁用分類磚塊呈現，點一下就能進入該分類，也可以直接搜尋設定
- **可設為預設檔案總管**：也能取代其他程式的「開啟／另存新檔」對話方塊
- **繁體中文介面**
- **不收集使用資料**

## 下載

到 [Releases](../../releases/latest) 下載最新版的 `KC-FILE-Setup.exe`。

## 系統需求

- Windows 10 / 11（64 位元）
- 目前不支援 ARM 處理器的電腦

## 安裝

1. 執行 `KC-FILE-Setup.exe`，出現系統管理員權限提示時按「是」（安裝時要匯入簽章憑證）。
2. 安裝完成後，就能從開始功能表開啟 KC FILE。
3. 安裝新版會直接覆蓋舊版，原本的設定都會保留。
